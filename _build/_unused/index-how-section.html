How it works

무료진단부터 실행까지, 4단계

복잡한 준비 없이 신청 한 번으로 시작합니다.

  1. 무료진단 신청

    이름과 연락처만 남겨주세요. 농지 소재지·이용상태·받은 통지는 전화로 여쭤봅니다.

    소요 1분

  2. 현황·행정단계 확인

    취득연도, 실제 이용상태, 통지 내용을 확인해 지금 어느 단계이고 기한이 얼마나 남았는지 정리합니다.

    1~3일

  3. 방향 설계

    실제 영농 전환 / 적법한 임대 가능성 검토 / 매도·매도위탁 / 전문가 상담 중 가능한 선택지를 제시하고, 필요한 서비스 하나만 추천합니다.

    리포트 또는 전화 안내

  4. 실행 · 기록

    영농설계와 경작 동반 서비스로 실행하고, 작업사진과 관리기록을 남깁니다. 연간 관리 컨설팅으로 다음 작업을 안내합니다.

    연중
