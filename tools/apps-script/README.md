# 무료진단 신청 → 관리자 목록(구글 시트) 저장 설정

신청폼에서 받은 이름·연락처가 **구글 시트 '신청목록'** 에 한 줄씩 쌓이고,
홈페이지의 **`admin.html`** 에서 목록을 보고 상태(신규/연락중/완료/보류)·메모를 관리합니다.
새 신청이 오면 이메일 알림도 받을 수 있습니다. 비용은 없습니다.

## 1. 구글 시트 만들기
1. https://sheets.new 에서 새 시트를 만들고 이름을 `올바른농지 신청목록` 등으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.

## 2. 코드 넣기
1. 편집기에 있는 내용을 모두 지우고 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
2. 맨 위 설정 세 줄을 수정합니다.
   - `ADMIN_KEY` — admin.html에서 입력할 관리자 키. 길고 추측하기 어려운 문자열로 (예: `nongji-2026-Xk93pQ`)
   - `NOTIFY_EMAIL` — 새 신청 알림을 받을 메일 주소. 필요 없으면 `''` 그대로
3. 저장(💾).

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 유형 선택(⚙️) → **웹 앱**
3. 설명: `lead v1` / **실행 사용자: 나** / **액세스 권한: 모든 사용자**
4. **배포** → 권한 승인(내 계정 선택 → "고급" → "이동" → 허용)
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 4. 홈페이지에 연결
`assets/site.js` 맨 위 CONFIG에 넣습니다.
```js
FORM_ENDPOINT: "https://script.google.com/macros/s/....../exec",
```
저장 후 빌드(`python _build/build.py`) → 배포.

## 5. 관리자 화면
- 사이트의 `admin.html` 을 엽니다 (메뉴에는 없음, 주소를 직접 입력).
- 관리자 키를 입력하면 목록이 보입니다. 키는 브라우저에만 저장됩니다.
- 상태·메모를 바꾸고 **저장**을 누르면 시트에 반영됩니다.
- 시트를 직접 열어 편집해도 됩니다 (첫 행 제목은 바꾸지 말 것).

## 확인 방법
- 사이트에서 이름·연락처를 넣고 신청 → 시트에 새 행이 생기면 성공.
- 안 되면: 배포 액세스 권한이 "모든 사용자"인지, URL이 `/exec`로 끝나는지 확인.
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 편집(✏️) → 버전: 새 버전 → 배포** 를 해야 반영됩니다. URL은 그대로입니다.

## 참고
- Formspree 등 다른 폼 서비스를 쓰려면 그 엔드포인트를 `FORM_ENDPOINT`에 넣으면 됩니다(JSON POST). 이 경우 관리자 목록은 해당 서비스 대시보드에서 봅니다.
- 시트 열: 접수일시 · 상태 · 메모 · 이름 · 연락처 · 신청일시 · 페이지 (폼 항목이 늘면 열이 자동으로 추가됩니다)
